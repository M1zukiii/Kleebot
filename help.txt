Kleebot 指令：
`/play` / `/播放` 播放 YouTube / B站 / NicoNico / Spotify 链接，或直接搜索歌曲
`/join` / `/加入` 加入你所在的语音频道
`/queue` / `/队列` 查看当前播放队列
`/nowplaying` / `/正在播放` 查看当前歌曲、队列数量、音量、滤镜和循环状态
`/shuffle` / `/打乱` 打乱当前等待队列
`/repeat` / `/循环` 设置循环模式：off、one、queue
`/skip` / `/跳过` 跳过当前正在播放的歌曲
`/pause` / `/暂停` 暂停当前播放
`/resume` / `/继续` 继续播放暂停中的歌曲
`/stop` / `/停止` 停止播放，并清空当前队列
`/leave` / `/离开` 离开语音频道
`/volume` / `/音量` 调整音量
`/filter` / `/滤镜` 设置音频滤镜：off、bassboost、nightcore、vaporwave、karaoke
`/profile` / `/档案` 查看你的点歌次数、求签次数和历史最好签
`/bomb` / `/炸弹` 让 Klee 炸一个目标
`/help` / `/帮助` 查看这段指令说明
`/fortune` / `/求签` 抽取今日幸运签
文字指令：`{PREFIX}play <链接或歌名>`、`{PREFIX}join`、`{PREFIX}queue`、`{PREFIX}nowplaying`、`{PREFIX}shuffle`、`{PREFIX}repeat <mode>`、`{PREFIX}skip`、`{PREFIX}stop`、`{PREFIX}leave`、`{PREFIX}filter <mode>`、`{PREFIX}profile`、`{PREFIX}bomb @目标`、`{PREFIX}求签`、`{PREFIX}help`
