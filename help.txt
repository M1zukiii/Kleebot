Kleebot 指令：
`/自治开启 目标` / `!自治开启 目标` — 开启持续观察；三次有效警告后继续违规，禁言60秒。
`/自治暂停` / `!自治暂停` — 暂停自主动作。
`/自治状态` / `!自治状态` — 查看目标、状态和近期执行记录。
`/禁言 成员 分钟 原因` 或 `!禁言 @成员 分钟 原因` — 禁言后公开显示执行者、时长、解除时间和原因。
`/解除禁言 成员 原因` 或 `!解除禁言 @成员 原因` — 提前解除禁言并公开原因。双方需要禁言成员权限及正确角色层级。
`/play` / `/播放` 播放 YouTube / B站 / NicoNico / Spotify 链接，或直接搜索歌曲
`/playlist` / `/playalbum` / `/专辑` 播放专辑、歌单、合集或列表链接
`/join` / `/加入` 加入你所在的语音频道
`/queue` / `/队列` 查看当前播放队列
`/nowplaying` / `/正在播放` 查看当前歌曲、队列数量、音量、滤镜和循环状态
`/shuffle` / `/打乱` 打乱当前等待队列
`/repeat` / `/循环` 设置循环模式：off、one、queue
`/skip` / `/跳过` 跳过当前正在播放的歌曲
`/pause` / `/暂停` 暂停当前播放
`/resume` / `/继续` 继续播放暂停中的歌曲
`/stop` / `/停止` 停止播放，并清空当前队列
`/leave` / `/离开` 离开语音频道
`/volume` / `/音量` 调整音量
`/filter` / `/滤镜` 设置音频滤镜：off、bassboost、nightcore、vaporwave、karaoke
`/profile` / `/档案` 查看你的点歌次数、求签次数和历史最好签
`/nickname` / `/称呼` 设置 Klee 对你的称呼
`/afk` / `/离开状态` 设置 AFK 状态，别人 @ 你时 Klee 会提醒
`/leaderboard` / `/排行榜` 查看排行榜：plays、fortunes、luck、bombed
`/bomb` / `/炸弹` 消耗 1 个炸弹，让 Klee 炸一个目标
`/imagine` / `/生图` 根据描述生成图片；可选方图、竖图、横图；模式选“大白话”会自动整理，选“提示词/标签”会原样发送；negative 可选默认、关闭或自定义
`/promptgen` / `/提示词` 只把大白话整理成 NovelAI 提示词，不生图
`/naiusage` / `/额度` 查看 NovelAI 模型、Anlas 和省 Anlas 设置
`/help` / `/帮助` 查看这段指令说明
`/fortune` / `/求签` 抽取今日幸运签，并领取 3 个炸弹
文字指令：`{PREFIX}play <链接或歌名>`、`{PREFIX}join`、`{PREFIX}queue`、`{PREFIX}nowplaying`、`{PREFIX}shuffle`、`{PREFIX}repeat <mode>`、`{PREFIX}skip`、`{PREFIX}stop`、`{PREFIX}leave`、`{PREFIX}filter <mode>`、`{PREFIX}profile`、`{PREFIX}nickname <称呼>`、`{PREFIX}afk <原因>`、`{PREFIX}leaderboard <category>`、`{PREFIX}bomb @目标`、`{PREFIX}生图 <大白话描述>`、`{PREFIX}生图 --竖图 <大白话描述>`、`{PREFIX}生图 --横图 --tags <提示词标签>`、`{PREFIX}生图 --no-negative <描述>`、`{PREFIX}生图 --negative "lowres, bad anatomy" <描述>`、`{PREFIX}提示词 --竖图 <大白话描述>`、`{PREFIX}naiusage`、`{PREFIX}求签`、`{PREFIX}help`


!forgetchat / !清除聊天 — 清除当前频道的近期聊天记忆；服务器内需要管理消息权限。
